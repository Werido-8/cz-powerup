## 高优先级结论

1. P0：上传、审批、权限、预览、编辑保存均需要后端接口和审计，当前不能按“已完成”宣讲。
2. P0：修复“我的上传 > 驳回原因”错误页。
3. P0：审批台单条通过/驳回应有确认、意见、接口、审计日志。
4. P0：统一文件状态、解析状态、发布状态，不要混用。
5. P1：补无权限库、权限申请、人员/角色真实数据的完整场景。
