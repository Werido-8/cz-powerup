
# 文件列表批量操作工具栏原位切换改造 Prompt

请基于当前项目已有的文件列表页面，对“文件多选后的批量操作区域”进行交互和 UI 改造。

本次改造的核心目标是：

> 不再在搜索工具栏和表格表头之间动态插入一整行批量操作栏，而是在用户选中文件后，将原有搜索工具栏原位切换为批量操作工具栏。

必须保证：

- 工具栏整体高度不变；
- 工具栏上下边界不变；
- 表格表头位置不变；
- 文件行位置不发生上下跳动；
- 选中和取消选择时，仅切换工具栏内部内容；
- 不新增第二行批量操作区域。

请先阅读并理解当前文件列表、搜索工具栏、文件选择状态、分页、批量下载和批量删除相关代码，再进行修改。

---

# 一、改造前先检查

请先确认以下内容：

1. 当前文件列表页面组件；
2. 搜索工具栏对应组件；
3. 表格或列表组件；
4. 文件多选状态存储位置；
5. 表头全选逻辑；
6. 当前页选择和跨页选择逻辑；
7. 批量下载接口；
8. 批量移动接口；
9. 批量删除接口；
10. 当前项目使用的 Checkbox、Button、Tooltip、Dropdown、Dialog 和图标库；
11. 是否存在多个页面复用同一套文件列表；
12. 当前批量操作行是如何动态插入和移除的。

不要复制一套新的文件列表组件，也不要破坏已有的搜索、筛选、分页和文件操作逻辑。

优先通过重构现有工具栏组件实现。

---

# 二、当前问题

当前页面在未选择文件时，结构为：

```text
搜索工具栏
表格表头
文件列表
````

选中文件后，结构变成：

```text
搜索工具栏
批量操作工具栏
表格表头
文件列表
```

这会导致：

* 表格整体向下移动；
* 用户刚选中的文件位置发生变化；
* 取消选择后表格再次向上移动；
* 页面产生明显跳动；
* 搜索工具栏和批量操作栏同时存在，视觉层级过多；
* 批量操作栏看起来像临时插入的内容；
* 连续勾选、取消时页面稳定性较差。

本次需要彻底取消这种“动态插入第二行”的方式。

# 三、目标交互

## 3.1 默认状态

当 `selectedFileIds.length === 0` 时，显示原有搜索工具栏：

```text
[全文] [文件名] [请输入全文关键词]      [上传] [卡片] [表格] [排序] [刷新]
```

保留当前页面已有功能：

* 搜索类型切换；
* 搜索输入框；
* 上传；
* 卡片视图；
* 表格视图；
* 排序；
* 刷新；
* 其他已有筛选项。

不要改变原有业务逻辑。

---

## 3.2 批量选择状态

当 `selectedFileIds.length > 0` 时，在原工具栏相同位置显示批量操作工具栏：

```text
[✓] 已选择 5 个文件               [批量下载] [移动到] [批量删除] [取消选择]
```

要求：

* 不保留默认搜索控件；
* 不在下方新增一行；
* 表格表头的位置与默认状态完全一致；
* 工具栏高度保持不变；
* 工具栏容器宽度保持不变；
* 工具栏左右内边距保持一致；
* 只替换工具栏内部的左、右区域内容。

推荐逻辑：

```ts
const isBatchMode = selectedFileIds.length > 0;
```

渲染结构建议：

```tsx
<FileToolbar className={isBatchMode ? 'is-batch-mode' : ''}>
  {isBatchMode ? (
    <BatchToolbarContent />
  ) : (
    <DefaultToolbarContent />
  )}
</FileToolbar>
```

实际代码需按照当前项目技术栈和组件结构调整，不要为了套用示例破坏现有架构。

# 七、选择当前页与全部结果

需要区分以下状态：

1. 仅选择当前页部分文件；
2. 选择当前页全部文件；
3. 选择全部搜索结果；
4. 取消全部选择。

如果当前项目暂时只支持当前页选择，可先保留现有逻辑，不要伪造跨页选择。

如果项目已经支持或准备支持跨页选择，可以在左侧增加轻量入口：

```text
已选择本页 10 个文件，选择全部 25 个文件
```

推荐结构：

```tsx
<div className="batch-toolbar__summary">
  <span>已选择本页 10 个文件</span>
  <button type="button" className="batch-toolbar__select-all">
    选择全部 25 个文件
  </button>
</div>
```

样式：

```css
.batch-toolbar__select-all {
  padding: 0;
  border: 0;
  background: transparent;
  color: rgb(52, 155, 172);
  font-size: 14px;
  cursor: pointer;
}
```

要求：

* 仅在当前页全部选中、但结果总数大于当前页数量时显示；
* 选择全部结果后，文案切换为“已选择全部 25 个文件”；
* 取消选择时清理跨页选择状态；
* 搜索条件、筛选条件或分页变化时，需要明确处理选择状态；
* 不允许把上一个查询条件的文件选择带入新结果。

# 十一、工具栏切换动画

工具栏切换时不要瞬间闪变，也不要做高度展开或收起动画。

建议使用内容层淡入淡出：

```css
.toolbar-content-enter-active,
.toolbar-content-leave-active {
  transition:
    opacity 160ms ease,
    transform 160ms ease;
}

.toolbar-content-enter-from {
  opacity: 0;
  transform: translateX(4px);
}

.toolbar-content-leave-to {
  opacity: 0;
  transform: translateX(-4px);
}
```

React 项目可使用项目已有动画组件或 CSS transition。

要求：

* 动画总时长控制在 `140～180ms`；
* 不改变外层容器高度；
* 不改变表格的纵向位置；
* 不使用 `max-height` 动画；
* 不使用明显滑动；
* 用户快速勾选和取消时不能出现重影或两个工具栏同时停留。

如项目没有统一动画方案，优先使用简单 CSS，不额外引入动画依赖。

# 十二、表头 Checkbox

当前页面是文件多选场景，建议将表头和文件行的选择控件改为标准方形 Checkbox。

原因：

* 方形 Checkbox 表达多选；
* 圆形控件更容易被理解为单选 Radio；
* 方形 Checkbox 更容易表达半选状态。

状态要求：

## 未选择

```text
□
```

## 部分选择

```text
▣
```

需要使用组件库标准 `indeterminate` 状态，不要手动画一个横杠。

## 当前页全部选择

```text
☑
```

## 点击逻辑

* 未选择时点击表头 Checkbox：选择当前页全部可选文件；
* 部分选择时点击：选择当前页全部可选文件；
* 当前页全部选择时点击：取消当前页全部选择；
* 禁用文件或无权限文件不计入可选数量；
* 当前页切换后，按产品现有规则决定是否保留其他页选择。

如果系统已经全局统一使用圆形多选控件，先检查设计规范和影响范围。若仅当前页面误用了圆形控件，则改为方形 Checkbox。

# 十四、搜索、分页和筛选变化时的选择状态

请明确处理以下情况。

## 搜索关键词改变

建议：

* 清空当前选择；
* 退出批量模式；
* 保留新的搜索条件。

避免选择列表中已经不可见的旧文件。

## 筛选条件改变

建议同样清空选择，除非当前项目已有明确的跨筛选选择机制。

## 切换知识库或目录

必须清空：

* 已选择文件；
* 全选状态；
* 跨页选择状态；
* 批量工具栏状态。

## 分页切换

请按当前产品需求选择一种策略，并保持一致：

### 策略 A：只支持当前页选择

切页后清空选择。

### 策略 B：支持跨页选择

切页后保留已经选择的文件，并在批量工具栏中显示总选择数量。

不要出现：

* 工具栏显示已选 5 个；
* 当前页没有任何 Checkbox 被选中；
* 用户却不知道选择来自其他页面。

如果支持跨页选择，需要在文案或 Tooltip 中明确说明。

# 十五、批量操作可用性

根据文件状态判断批量操作是否可执行。

例如：

## 批量下载

只有用户有下载权限、且文件存在时可操作。

如果选中的文件中包含不可下载文件，需要：

* 禁用批量下载并说明原因；或
* 下载可下载文件并明确提示跳过数量。

不要静默失败。

## 批量移动

需要检查：

* 用户是否有目标目录权限；
* 文件是否正在解析；
* 是否允许跨知识库移动；
* 移动后是否需要重新解析；
* 是否影响文件权限和引用。

如果首版只支持当前知识库内移动，需在选择器中限制目标范围。

## 批量删除

需要检查：

* 用户是否有删除权限；
* 是否存在正在解析的文件；
* 是否存在系统内置或不可删除文件；
* 是否使用逻辑删除或回收站。

## 批量停用

如果使用批量停用替代移动到：

* 只处理当前已启用文件；
* 已停用文件不重复处理；
* 未解析、解析中、解析失败文件是否允许停用，需要按业务规则处理；
* 完成后更新文件列表和开关状态。

# 十六、Loading 和防重复提交

批量操作执行过程中：

* 对应按钮显示 Loading；
* 禁止重复点击同一操作；
* 其他批量按钮是否禁用，按项目现有规则处理；
* 不要立即清空选择；
* 操作成功后再清理已成功处理的文件；
* 操作失败时保留选择，方便用户重试；
* 显示明确成功或失败提示。

例如：

```text
已下载 5 个文件
已移动 5 个文件
已删除 5 个文件
其中 2 个文件操作失败
```

如果部分成功，需要说明成功和失败数量。

---

# 十七、权限控制

批量工具栏中的操作按钮必须按当前用户权限展示。

例如：

* 无下载权限：不显示批量下载，或禁用并说明；
* 无移动权限：不显示移动到；
* 无删除权限：不显示批量删除；
* 普通用户页面只展示用户有权执行的批量操作；
* 管理员页面按管理权限展示完整操作。

不要只在前端隐藏按钮，后端接口仍需执行权限校验。

---

# 十八、响应式和窄屏处理

桌面端优先保持左右布局。

当工具栏空间不足时：

* 左侧已选择数量保持可见；
* 右侧低频操作可以折叠进“更多批量操作”；
* 不允许按钮换成两行导致工具栏高度变化；
* 不允许表格因此向下移动。

推荐窄屏结构：

```text
已选择 5 个文件       [批量下载] [更多] [取消选择]
```

“更多”中放置：

```text
移动到
批量删除
批量停用
```

如果当前系统只面向 1920×1080 桌面端，也需要保证浏览器宽度缩小时不溢出。

# 十九、无障碍和键盘交互

需要保证：

* Checkbox 支持键盘聚焦；
* Space 可以切换选择；
* 表头全选支持半选状态；
* 按钮有明确 `aria-label`；
* 批量模式切换后不要抢走用户当前焦点；
* 取消选择后焦点返回合理位置；
* Tooltip 不能作为唯一的操作说明；
* 危险操作必须有确认弹窗。

---

# 二十、视觉禁区

禁止出现以下情况：

* 选中后新增第二行批量操作栏；
* 选中后表格整体向下移动；
* 取消选择后表格整体向上移动；
* 默认工具栏和批量工具栏同时显示；
* 批量工具栏高度大于默认工具栏；
* 使用高饱和主题色铺满整行；
* 所有批量按钮都使用实心主题色；
* 批量删除使用大面积红色实心按钮；
* 动画改变容器高度；
* 选中状态下文件行高度变化；
* 搜索条件变化后仍保留失效选择；
* 使用圆形 Radio 表达多选，除非系统已有统一规范且不可调整；
* 为本功能复制一套新的文件列表和选择状态逻辑。

# 二十一、建议组件拆分

可根据当前项目结构进行调整。

```tsx
<FileToolbar
  selectedCount={selectedFileIds.length}
  totalCount={total}
  isAllResultsSelected={isAllResultsSelected}
>
  {isBatchMode ? (
    <BatchFileActions
      selectedIds={selectedFileIds}
      onDownload={handleBatchDownload}
      onMove={handleBatchMove}
      onDelete={handleBatchDelete}
      onCancelSelection={clearSelection}
    />
  ) : (
    <FileSearchActions
      searchType={searchType}
      keyword={keyword}
      onSearch={handleSearch}
      onUpload={handleUpload}
      viewMode={viewMode}
      onViewModeChange={setViewMode}
      onSort={handleSort}
      onRefresh={handleRefresh}
    />
  )}
</FileToolbar>
```

要求：

* 默认工具栏和批量工具栏共用外层容器；
* 选择状态继续由当前文件列表上层统一管理；
* 不要在两个工具栏中分别维护一套选择状态；
* 不要修改已有接口参数语义。

# 二十二、验收标准

请逐项验证：

1. 未选择文件时显示原有搜索工具栏；
2. 选中文件后，原位置切换成批量工具栏；
3. 不新增第二行；
4. 工具栏高度前后一致；
5. 表格表头位置前后一致；
6. 文件列表没有上下跳动；
7. 左侧正确显示已选择文件数量；
8. 选择数量实时更新；
9. 批量下载是普通次级按钮；
10. 移动到是普通次级按钮；
11. 批量删除使用危险弱化样式；
12. 取消选择是轻量文字按钮；
13. 工具栏批量模式只有极浅主题色背景；
14. 切换动画不改变高度；
15. 动画时间控制在 140～180ms；
16. 表头 Checkbox 支持未选、半选、全选；
17. 表头全选只处理当前可选文件；
18. 取消选择后不清空搜索条件；
19. 搜索、切换知识库或目录时正确清理选择；
20. 批量操作 Loading 状态完整；
21. 批量操作失败时保留选择；
22. 用户权限正确控制按钮显示；
23. 窄屏下按钮不会换行撑高工具栏；
24. 未复制新的文件列表和选择逻辑；
25. 现有上传、搜索、筛选、排序、刷新和分页功能不受影响。
