# “我的上传”页面左侧区域重构 Prompt

请基于当前项目已有的“我的上传”页面，对左侧区域进行整体重构优化。

## 一、改造目标

当前“我的上传”页面左侧过于空泛，只有简单的说明卡片，缺少实际操作价值。  
本次改造目标是：

> 将左侧从“说明型空白侧栏”升级为“上传工作台侧栏”。

左侧不再只是展示“我的上传”标题，而是承担以下职责：

1. 作为上传入口；
2. 作为上传任务导航区；
3. 作为待处理事项快捷入口；
4. 作为常用目标知识库快捷入口。

请注意：

- 不要简单增加装饰内容；
- 不要复制一个知识库树页面到这里；
- 不要让左侧变成纯展示信息；
- 要强调“上传任务管理”和“快速处理”的功能价值。

---

## 二、整体结构

请将左侧区域拆成 4 个主要模块：

### 1. 顶部主卡片：我的上传
内容包括：
- 标题：“我的上传”
- 副标题：“追踪审批、解析与发布进度”
- 主按钮：“上传文件”
- 次级入口：“选择知识库上传”

要求：
- 主按钮为主题色按钮；
- 支持图标 + 文字；
- 次级入口可以是轻量按钮或文字按钮；
- 卡片风格与当前系统保持一致，圆角 8~12px；
- 不使用过大装饰插画；
- 视觉上比现在更“功能化”，不要只是介绍卡片。

交互要求：
- 点击“上传文件”：打开上传弹窗/抽屉；
- 上传流程支持先选目标知识库，再上传文件；
- 支持拖拽上传；
- 支持回填最近使用的知识库。
- 点击“选择知识库上传”：优先打开知识库树选择器，再进入上传流程。

---

### 2. 上传任务导航
在左侧增加一个“上传任务”分组，用于替代单一的“我的上传列表”概念。

建议包含：
- 全部上传
- 待审核
- 解析中
- 已发布
- 需处理

每一项都要有：
- 图标
- 文案
- 数量 badge

建议示例：
- 全部上传（7）
- 待审核（1）
- 解析中（2）
- 已发布（1）
- 需处理（2）

交互要求：
- 点击左侧导航项，右侧表格自动切换到对应状态；
- 顶部筛选项同步变化；
- 当前选中项保持高亮；
- 高亮样式沿用当前系统风格：浅主题色背景 + 左侧竖线；
- “需处理”应聚合异常或需要用户动作的内容（如驳回、解析失败等）。

不要只做静态菜单，必须和右侧筛选联动。

---

### 3. 待我处理
增加一个“待我处理”分组，用于展示当前需要用户立即处理的问题。

建议项：
- 驳回待修改（1）
- 解析失败待重试（1）
- 待审核可撤回（1）

交互要求：
- 点击“驳回待修改”：右侧自动筛选到驳回记录，并能突出显示驳回原因；
- 点击“解析失败待重试”：右侧自动筛选到解析失败记录，并能执行重试；
- 点击“待审核可撤回”：右侧筛选到待审核记录，并引导执行“撤回申请”；
- 每项都支持 badge 数量；
- 这部分要比普通导航更强调“待办感”。

样式要求：
- 可以使用轻量状态色；
- 异常项 badge 可使用浅红 / 浅橙；
- 不要使用大面积高饱和红色。

---

### 4. 常用目标知识库
增加“常用目标知识库”分组，用于支持快速上传到常用知识库。

内容建议：
- 展示用户最近使用 / 置顶的 3~5 个知识库；
- 每项显示知识库名称；
- 每项右侧提供轻量操作：“上传到此库”；
- 底部增加“更多知识库 >”入口。

交互要求：
- 点击“上传到此库”：直接打开上传弹窗，并自动回填目标知识库；
- 点击“更多知识库 >”：打开完整知识库树选择器；
- 不要把完整知识库树常驻在左侧；
- 优先展示常用库，完整树通过选择器/抽屉方式展开。

---

## 三、设计原则

### 1. 不要让左侧过于空
当前问题是左侧太空，信息密度过低。  
改造后应让左侧具备实际操作价值，但不能堆满内容。

### 2. 不要直接常驻整棵知识库树
“我的上传”页的核心是任务处理，不是树浏览。  
完整知识库树可以通过点击“选择知识库上传”或“更多知识库”展开。

### 3. 避免卡片堆卡片
建议：
- 顶部主卡片独立；
- 下面各分组使用轻量分区；
- 不要每个分组都做成厚重卡片；
- 使用标题 + 列表 + 轻边框/分隔线即可。

### 4. 视觉风格保持系统统一
要求：
- 使用当前系统主题色 RGB(52,155,172)；
- 圆角控制在 8~12px；
- 左侧分组标题清晰；
- 项目高度统一（建议 36~40px）；
- badge 高度控制在 18~20px；
- 图标统一使用当前系统线性图标；
- 不要使用 Emoji；
- 不要加入复杂插画。

## 五、与右侧区域的联动

本次改造必须处理好左侧与右侧内容的联动关系：

### 左侧任务导航 -> 右侧表格筛选
- 点击“待审核”，右侧审批状态筛选同步到待审核；
- 点击“解析中”，右侧解析状态筛选同步到解析中；
- 点击“已发布”，右侧显示已发布项；
- 点击“需处理”，右侧聚焦异常或待处理记录。

### 左侧待我处理 -> 右侧问题聚焦
- 点击“解析失败待重试”，右侧展示解析失败行，并可直接重试；
- 点击“驳回待修改”，右侧展示驳回记录，并突出“驳回原因”；
- 点击“待审核可撤回”，右侧展示待审核记录，并保留“撤回申请”动作。

### 左侧常用知识库 -> 上传弹窗
- 点击“上传到此库”，打开上传流程并回填目标知识库；
- 点击“更多知识库”，打开完整知识库树选择器。

---

## 六、不要做的事情

禁止：
- 只在左侧加一些说明文字凑内容；
- 直接把整棵知识库树塞满左侧；
- 把左侧做成大而空的装饰面板；
- 每个分组都套厚重卡片；
- 仅做静态展示，不做和右侧的状态联动；
- 复制一个新的“知识库页面”结构到我的上传页；
- 增加太多视觉噪音，如过多大面积主题色、复杂渐变、夸张阴影。
