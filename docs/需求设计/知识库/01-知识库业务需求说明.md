# 知识库模块 · 业务需求说明

> **版本**：v1.7 · 2026-07-07  
> **依据**：[知识库需求沟通纪要-老总沟通](./知识库需求沟通纪要-老总沟通.md) · 原 v0.3 权限体系  
> **范围**：第一期（MVP）  
> **说明**：本文档仅描述**用户要做什么、为什么做**，不涉及菜单层级、路由与页面布局（见 02 系统需求）。需求清单中 **标题** 为简短概括，**业务需求** 为完整描述。

---

## 一、模块定位

知识库是平台的**文件底座**，用于存放电厂规程、制度、技术标准等文档。后续学习、考试、AI 问答等模块均从此获取资料。

**第一期业务目标**：存得住、找得到、管得住——先把文档的上传、审批、查看、权限等基础能力做全做顺。

---

## 二、用户角色


| 角色         | 典型使用者          | 主要职责                                |
| ---------- | -------------- | ----------------------------------- |
| **普通员工**   | 运行值班员、技术员等     | 快速找到有权查看的文档；上传个人资料；向公共/专业库提交文档并跟踪审批 |
| **部门管理员**  | 各部门负责人或指定管理员   | 维护本部门相关知识库；审批员工上传；配置成员权限            |
| **知识库管理员** | 平台指定管理员 / 实施人员 | 维护分类与知识库结构；管理公共库；审批公共库上传；全库权限治理     |


> 同一人可同时具备多个角色（如既是管理员又是普通员工），业务上应能分别完成对应操作。

### 3.1 业务入口概览

从**用户要完成的事**出发，知识库模块需区分以下几类入口（不叫「菜单怎么实现」，只说明用户能去哪、干什么）：


| 用户意图     | 业务入口（用户侧说法） | 典型场景                  |
| -------- | ----------- | --------------------- |
| 按库查资料、上传 | **知识总览**   | 日常查阅某专业库、往指定库传文件      |
| 跨库找文件    | **所有文档**    | 不记得在哪个库，要一次性搜全部有权文件   |
| 个人事务     | **我的空间**    | 续看最近文件、管个人库、查上传审批进度   |
| 治理维护     | **知识库管理**   | 管理员后台：分类/知识库/审批/解析异常（与浏览分离） |


> **与系统需求的分工**：上述入口在系统里如何做成一级/二级菜单、默认打开哪一页、路由如何跳转，属于**系统需求**，见 [02-知识库系统需求说明](./02-知识库系统需求说明.md) §2.1，不在本文展开。

## 六、核心业务流程



### 6.1 员工按库浏览文档

```
员工点击系统菜单：知识库 → 知识总览（默认页）
  → 左侧：快速访问 / 知识库树 选中某个库
  → 右侧：该库内文件列表
  → 点击文件 → 文件详情页（左切换文件 / 中预览 / 右 AI）
  → 顶部库名下拉可切换其他有权限的知识库 → 左侧列表更新 → 默认打开新库第一个文件
  → 或点击「返回知识总览」回到浏览页
```



### 6.1b 员工跨库查找文档

```
员工点击：知识库 → 所有文档（或知识总览页「所有文档」按钮）
  → 所有文档汇总页：全部有权访问的文件
  → 按分类 / 知识库 / 标签筛选、搜索排序
  → 点击文件 → 文件详情页
```



### 6.1c 员工访问个人事务

```
方式一：知识库 → 我的空间（左右分栏，默认右侧「最近访问」）
方式二：知识总览 → 左侧「我的」→ 我的空间
方式三：知识总览 → 快速访问 → 个人知识库（我的空间左侧树选中该库）
```



### 6.2 员工上传文档到公共/专业库

```
员工选择目标知识库（须有上传权限）
  → 上传文件
  → 若同名：选择「新版本」或「重命名」
  → 进入「待审批」队列
  → 管理员审批
      ├─ 通过 → 进入解析 → 解析完成 → 对有权限者可见
      └─ 驳回 → 仅上传者可见，可查看原因并重传
  → 员工在「我的空间」左侧「我的上传」、右侧列表中跟踪状态
  → 收到审批结果通知
```



### 6.3 员工申请知识库权限

```
员工发现某知识库无权限或权限不足
  → 点击「申请权限」
  → 选择权限类型（浏览 / 上传）+ 填写理由
  → 提交申请
  → 对应管理员审批
      ├─ 通过 → 自动获得权限，系统通知
      └─ 驳回 → 收到驳回通知，可重新申请
```



### 6.4 管理员维护知识库

**知识库管理员**：

```
登录 → 知识库管理（系统二级菜单）
  → 分类管理：维护分类树
  → 知识库：列表新建/编辑/停用/权限配置
  → 审批台：处理上传审批与权限申请
  → 解析异常：重试或删除失败文档
```

**部门管理员**（复用同一页面，无「分类管理」）：

```
登录 → 知识库管理
  → 知识库：本部门库列表，新建本部门库、编辑/停用/配权限
  → 审批台：本部门待审上传与权限申请
  → 解析异常：本部门失败文档
```

## 七、业务规则摘要



### 7.1 上传审批规则


| 上传者        | 目标库         | 是否审批      |
| ---------- | ----------- | --------- |
| 任意角色       | 个人库         | 免审批       |
| 知识库管理员     | 任意库         | 免审批       |
| 部门管理员      | 本部门库        | 免审批       |
| 部门管理员      | 其他部门库 / 公共库 | 需审批       |
| 普通员工（有上传权） | 部门库         | 需部门管理员审批  |
| 普通员工（有上传权） | 公共库         | 需知识库管理员审批 |
| 普通员工（无上传权） | 部门库 / 公共库   | 不可上传      |




### 7.2 知识库可见性规则


| 知识库状态   | 普通员工              | 部门管理员（本部门）      | 知识库管理员 |
| ------- | ----------------- | --------------- | ------ |
| 正常      | 按权限可见（含无权限库，选中后可申请） | ✅               | ✅      |
| **已停用** | ❌ 不可见、不可检索、不可访问   | ✅ 仅管理端可见，可查看/恢复 | ✅      |


> 停用后库内文档**数据保留**，不对普通用户开放浏览；管理员在「知识库管理」中可查看停用库及其中文件（只读），必要时可重新启用。



### 7.3 文件可见性规则


| 文件状态 | 上传者 | 管理员 | 其他有浏览权的用户 |
| ---- | --- | --- | --------- |
| 待审批  | ✅   | ✅   | ❌         |
| 审批驳回 | ✅   | ✅   | ❌         |
| 解析中  | ✅   | ✅   | ❌         |
| 解析失败 | ✅   | ✅   | ❌         |
| 已发布  | ✅   | ✅   | ✅         |




### 7.4 版本管理规则

- 同库同名文件默认推荐「上传为新版本」，保留历史版本
- 列表默认展示当前版
- 历史版本可检索、可预览、可下载
- 历史版本不参与 AI 问答默认召回（当前版为准）
