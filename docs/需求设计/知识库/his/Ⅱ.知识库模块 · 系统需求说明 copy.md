# Ⅱ.知识库模块 · 系统需求说明

# 一. 知识库模块总览

| 页面    | 系统菜单名 | 页面定位                           | 落地                |
| ----- | ----- | ------------------------------ | ----------------- |
| 知识总览  | 知识总览  | 知识库首页; 左侧知识库树导航+右侧库内文件         | 默认页               |
| 全库资料  | 全库资料  | 全部有权访问库的文件汇总页                  | 二级菜单+总览页快捷按钮      |
|       | 文件详情页 | 单文件阅读：顶部库切换+左侧文件列表+中预览+右AI辅助内容 | 从任意列表进入           |
| 我的空间  | 我的空间  | 最近访问 / 个人知识库 / 我的上传记录 / 我的收藏   | 二级菜单独立也 + 总览页快捷按钮 |
| 知识库管理 | 知识管理  | 分类树维护 / 建库 / 权限 / 审批           | 二级菜单，仅管理员         |



# 二. 系统菜单结构

## 2.1 系统导航

```
知识库(一级)
├── 知识总览 (二级) 默认页
├── 全库资料 (二级)
├── 我的空间 (二级)
└── 知识管理 (二级) 仅管理员可见 

```

| 菜单   | 可见角色 | 说明                  |
| ---- | ---- | ------------------- |
| 知识总览 | 全员   | 按知识库树浏览，右侧展示选中库的文件  |
| 全库资料 | 全员   | 有权访问的全部文件汇总列表       |
| 我的空间 | 全员   | 个人知识库，我的上传，个人知识库，收藏 |
| 知识管理 | 管理员  | 分类树与知识库维护; 权限与文件的审批 |



## 2.2 页面跳转关系

| 起点页   | 操作              | 目标页                                                      |
| ----- | --------------- | -------------------------------------------------------- |
| 知识总览页 | 点击左侧\[全库资料]按钮   | 全库资料页                                                    |
| 知识总览页 | 快速访问 -> 个人知识库   | 我的空间 -> 个人知识库                                            |
| 知识总览页 | 快速访问 ->  某专业知识库 | 不跳转，同页右侧切换为该哭的文件列表                                       |
| 知识纵览页 | 点击右侧文件          | 文件详情页                                                    |
| 全库资料页 | 点击文件            | 文件详情页                                                    |
| 全库资料页 | 顶部返回按钮          | 知识总览页                                                    |
| 我的空间页 | 点击文件            | 文件详情页                                                    |
| 文件详情页 | 点击顶部返回按钮        | 若有知识库总览进入，则返回总览页，并保持上次选中的库；&#xA;&#xA;若由全库资料页进入，则返回全库资料页面 |
| 文件详情页 | 点击库名，下拉切换有权知识库  | 不跳转，同页左侧列表刷新为新库文件，默认预览库内第一个文件                            |
| 文件详情页 | 点击左侧文件列表的文件，快切  | 不跳转，切换预览内容，及右侧ai辅助内容                                     |

# 八.权限



## 8.1 权限层次

知识库内的权限分为2个层次：

```
层次1：【知识库权限】对知识库本身的新建，编辑，启停管理操作
层次2：【文件操作权限】进入x知识库后，对库内的文件进行具体的操作（上传，移动，增加，删除，更新，查看）
```

> 文件操作的权限绑定在单个知识库上，同一名员工，可以有A库的【可管理】维护权，即可以有对B库的【仅查看】权限；



### 8.2 权限分组

为降低配置复杂度，文件操作权限采用3个权限组（累计级别），高级别自动包含低级别能力，配置时只可以单选

| 权限组 | 界面展示名 | 界面副说明                         | 包含操作                        | 备注                                                                   |
| --- | ----- | ----------------------------- | --------------------------- | -------------------------------------------------------------------- |
| 查看组 | 仅查看   | 可预览、下载文件                      | 预览，下载                       |                                                                      |
| 贡献组 | 可贡献   | 在仅查看基础上，可上传文件；上传的文件须被审批       | 预览，下载，上传文件                  |                                                                      |
| 管理组 | 可管理   | 维护本库目录与文件；上传免审批；可审批他人向本库上传的文件 | 预览，下载，上传文件，&#xA;更新文件，审批文件上传 | 1.可管理是进入知识库内，对库内的维护能力, 不是对库本身;&#xA;2\. 本部门管理员，默认有部门下所有知识库的 \[可管理] 权限 |
