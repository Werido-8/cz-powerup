# Ⅰ.知识库模块 · 业务需求说明

# 一. 模块定位

知识库用于统一沉淀、查阅和管理电厂规程制度、国标、厂标、技标、培训资料等文档资料

本模块的业务目标是：

1. 让员工知道有哪些知识库，并能快速找到自己有权查看的文档
2. 让员工能围绕文档完成查阅、检索、下载、收藏、最近访问、上传和审批跟踪
3. 让管理员能完成知识库、文档、权限、上传审批和解析异常等治理工作

# 二. 用户角色


| 角色     | 使用者                 | 主要业务诉求                                    |
| ------ | ------------------- | ----------------------------------------- |
| 普通员工   | 值班员、技术员、培训人员等       | 查找资料、查看文档、下载文档、收藏文档、上传资料、跟踪上传审批状态、申请知识库权限 |
| 知识库管理员 | 平台指定管理员、培训老师、资料维护人员 | 维护知识库和分类、审批上传文档、处理权限申请、管理文档状态、处理解析异常      |
| 超级管理员 | 平台系统管理员 | 在知识库管理员能力之外，查看跨专业库和个人库的全库文件汇总，用于全局监管与审计 |


> 一期不拆分部门管理员、专业管理员等多级管理角色；超级管理员仅承担全局汇总查看，不替代知识库管理员的日常维护职责。后续如需按部门或专业分级管理，再扩展角色和授权规则。

# 三. 业务需求清单

## 3.1 知识库浏览与发现


| 编号    | 业务点       | 要做的事情                                         |
| ----- | --------- | --------------------------------------------- |
| BR-01 | 浏览知识库     | 员工进入知识库模块后，能够看到知识库的整体范围，知道当前有哪些公共、专业或个人相关的知识库 |
| BR-02 | 查看有权限知识库  | 员工可以进入自己有权限的知识库，查看该知识库下的文档资料                  |
| BR-03 | 看到无权限知识库  | 员工可以看到无权限知识库的基础信息，知道该知识库存在，但不能查看库内文档          |
| BR-04 | 申请知识库权限   | 员工对某个知识库无权限或权限不足时，可以提交权限申请，并填写申请理由            |
| BR-05 | 按知识库查看文档  | 员工可以选择某个知识库，只查看该知识库下的文档                       |
| BR-06 | 查看全部可访问文档 | 员工可以一次性查看自己有权访问的所有知识库文档，不需要逐个知识库翻找            |




## 3.2 文档查找与筛选


| 编号    | 业务点    | 要做的事情                                      |
| ----- | ------ | ------------------------------------------ |
| BR-07 | 文档搜索   | 员工可以按文件名或已完成解析的正文内容关键词搜索文档，快速找到需要的资料；正文检索仅在本人有查看权限的已发布文档范围内生效 |
| BR-08 | 文档筛选   | 员工可以按知识库、文件类型、上传时间、生效年份、标签等条件筛选文档          |
| BR-09 | 文档排序   | 员工可以按最近更新、上传时间、文件大小、文件名称等常用条件排序文档               |
| BR-10 | 跨库查找   | 员工不确定文档属于哪个知识库时，可以在全部可访问文档范围内查找            |
| BR-11 | 单库精确筛选 | 员工进入某个具体知识库后，可以使用该知识库对应的标签、年份、专业等属性进行更精确筛选 |




## 3.3 文档查看与使用


| 编号    | 业务点      | 要做的事情                                      |
| ----- | -------- | ------------------------------------------ |
| BR-12 | 在线预览文档   | 员工可以打开文档并在线阅读原文                            |
| BR-13 | 当前库内切换文档 | 员工查看某个文档时，可以继续切换查看当前知识库内的其他文档              |
| BR-14 | 下载文档     | 员工对有权限的文档可以下载到本地使用                         |
| BR-15 | 收藏文档     | 员工可以收藏常用或重要文档，后续在个人相关入口中快速找到               |
| BR-16 | 查看收藏文档   | 员工可以集中查看自己收藏过的文档，并可取消收藏                    |
| BR-17 | 查看历史版本   | 员工查看文档时，可以查看该文档已有的历史版本                     |
| BR-18 | 查看解析状态   | 员工可以知道自己上传或关注的文档是否已完成解析；解析未完成前，不要求支持正文内容检索 |




## 3.4 最近访问与快速访问


| 编号    | 业务点      | 要做的事情                          |
| ----- | -------- | ------------------------------ |
| BR-19 | 记录最近访问   | 员工访问过的知识库和文档需要形成最近访问记录，按今天、本周、更早时间分组，方便继续查看  |
| BR-20 | 查看更多访问历史 | 最近访问可以默认展示少量记录，但员工应能查看更多历史访问记录 |
| BR-21 | 固定常用知识库  | 员工可以把常用知识库固定为快速访问对象，也可以取消固定            |
| BR-22 | 固定常用文档   | 员工可以把常用文档固定（置顶）为快速访问对象，也可以取消固定；文件置顶即加入快速访问区，不改变其在文档列表中的排序位置 |




## 3.5 我的空间


| 编号    | 业务点      | 要做的事情                                       |
| ----- | -------- | ------------------------------------------- |
| BR-23 | 查看个人相关内容 | 员工可以集中查看与自己相关的知识库内容，包括个人知识库、最近访问、我的收藏、我的上传等 |
| BR-24 | 管理个人知识库  | 员工拥有个人知识库，用于存放个人资料；可在个人空间中新增、重命名、删除、移动个人知识库，删除前需处理库内文件                          |
| BR-25 | 上传个人资料   | 员工可以向个人知识库上传文档，用于个人沉淀和后续查阅                  |
| BR-26 | 查看我的收藏   | 员工可以在个人相关内容中查看所有收藏文档，并可按文件名或正文检索、按最近更新/文件大小/文件名称排序                        |
| BR-27 | 查看我的上传   | 员工可以查看自己提交过的上传记录及处理状态                       |
| BR-50 | 维护个人分类   | 员工可以在个人知识库内新建、重命名、移动、删除分类目录，用于整理个人资料；删除前需处理目录内资料和子目录 |
| BR-51 | 整理个人资料   | 员工可以在个人分类目录之间移动个人文件；将个人文件移入专业库时，须具备目标库上传权限并进入非个人库审批流程 |




## 3.6 文档上传与审批


| 编号    | 业务点       | 要做的事情                                   |
| ----- | --------- | --------------------------------------- |
| BR-28 | 上传文档      | 员工可以向有上传权限的知识库提交文档                      |
| BR-29 | 选择目标知识库   | 员工上传文档时，需要明确文档要进入哪个知识库                  |
| BR-30 | 非个人库上传需审批 | 员工向公共、专业等非个人知识库上传文档后，需要管理员审批后才正式入库      |
| BR-31 | 个人库上传免审批  | 员工向个人知识库上传文档时，不需要管理员审批                  |
| BR-32 | 跟踪上传状态    | 员工可以查看自己上传文档的状态，包括待审批、已撤回、解析中、已停止、已发布、已驳回、解析失败等 |
| BR-33 | 查看驳回原因    | 上传被驳回时，员工可以查看驳回原因                       |
| BR-34 | 撤回待审批上传  | 员工可以撤回仍处于待审批状态的上传申请；撤回后不再进入审批和解析流程 |
| BR-52 | 查看上传进度与解析结果 | 员工可以查看审核进度、解析进度；解析完成后可查看文件、摘要、图片及关联题目等解析结果 |
| BR-53 | 停止或重试解析  | 员工可以停止本人仍在解析中的上传；解析失败时可查看异常原因并发起重新解析 |


> 上传被驳回后，本次上传流程结束，不再提供后续上传处理入口



## 3.7 权限申请与授权


| 编号    | 业务点       | 要做的事情                     |
| ----- | --------- | ------------------------- |

| BR-36 | 审批权限申请    | 管理员可以审批员工提交的知识库权限申请       |
| BR-37 | 授权角色访问    | 管理员可以通过角色给一组员工配置知识库访问权限   |
| BR-38 | 授权个人访问    | 管理员可以对单个员工单独配置某知识库的访问权限   |
| BR-39 | 查看最终可访问范围 | 员工实际可访问的知识库由角色授权和个人授权共同决定 |
| BR-54 | 获知审批结果    | 权限申请审批通过或驳回后，申请人应收到结果通知；驳回时可查看驳回原因 |

| ----- | ------- | ------------------------------ |

# 四. 核心业务流程



## 4.1 员工查找并查看文档

```text
员工进入知识库
  -> 浏览知识库或查看全部可访问文档
  -> 搜索、筛选或排序
  -> 打开文档在线预览
  -> 按需下载、收藏、查看历史版本
```



## 4.2 员工申请知识库权限

```text
员工看到无权限知识库
  -> 提交权限申请并填写理由
  -> 管理员审批
      -> 通过：员工获得对应权限
      -> 驳回：员工查看驳回结果，本次申请流程结束
```



## 4.3 员工上传文档

```text
员工选择上传文档
  -> 选择目标知识库
  -> 上传文件
      -> 个人知识库：直接进入解析和个人资料范围
      -> 非个人知识库：进入管理员审批
  -> 员工在我的上传中查看状态
      -> 审批通过：文档进入解析，解析完成后可被有权限用户查看
      -> 审批驳回：员工查看原因，本次上传流程结束
```



## 4.4 管理员治理知识库

```text
管理员进入知识库管理
  -> 维护知识库和分类
  -> 配置角色或个人访问权限
  -> 审批上传文档和权限申请
  -> 处理解析异常和库内文档问题
```



# 五. 业务规则



## 5.1 文档可见性


| 文档状态 | 上传人 | 管理员 | 其他有权限员工 |
| ---- | --- | --- | ------- |
| 待审批  | ✅   | ✅   | ❌       |
| 已撤回  | ✅   | ✅   | ❌       |
| 已驳回  | ✅   | ✅   | ❌       |
| 解析中  | ✅   | ✅   | ❌       |
| 已停止  | ✅   | ✅   | ❌       |
| 解析失败 | ✅   | ✅   | ❌       |
| 已发布  | ✅   | ✅   | ✅       |




## 5.2 上传审批


| 上传目标         | 是否需要审批  |
| ------------ | ------- |
| 个人知识库        | 不需要审批   |
| 公共、专业等非个人知识库 | 需要管理员审批 |

> 非个人知识库文档需先审批通过再触发解析，避免驳回后浪费解析资源；个人知识库上传后直接进入解析




## 5.3 文档操作权限


| 用户类型   | 可做的事情                                    |
| ------ | ---------------------------------------- |
| 普通员工   | 查看、搜索、预览、下载、收藏有权限的文档；上传文档；查看自己的上传记录      |
| 知识库管理员 | 在普通员工能力基础上，管理知识库、审批上传、审批权限、处理解析异常、管理库内文档 |
| 超级管理员 | 在知识库管理员能力基础上，查看全库文件汇总；不因汇总视图而获得对个人文件内容的任意下载或修改权限 |

## 5.4 上传状态与处理规则

| 状态 | 上传人可执行操作 | 处理规则 |
| --- | --- | --- |
| 待审批 | 查看进度、撤回申请 | 撤回后流程结束，不再通知审批人处理 |
| 已驳回 | 查看驳回原因 | 本次流程结束，不提供在线修改后再次提交入口 |
| 解析中 | 查看解析进度、停止解析 | 停止后进入已停止状态，不向其他用户发布 |
| 解析失败 | 查看异常原因、重新解析 | 重新解析沿用已审批通过的文件，不重新进入审批 |
| 已发布（解析完成） | 查看文件及解析结果 | 可展示摘要、图片和关联题目；可见范围仍受知识库权限控制 |

## 5.5 审批与通知规则

1. 上传审批列表至少展示文件名、目标知识库、提交人、提交时间、审批状态；权限申请列表至少展示申请人、目标知识库、申请理由、申请状态。
2. 审批通过或驳回均须向申请人通知结果；上传驳回必须填写原因，权限申请驳回应填写原因。
3. 审批进度和解析进度均按全部上传记录汇总展示，并可进入单条记录查看详情。

## 5.6 分类与移动规则

1. 公共、专业知识库使用管理员维护的分类树；个人知识库支持用户维护个人分类目录。
2. 个人文件可在个人分类目录内移动；移入专业库属于一次新的非个人库上传，需校验目标库上传权限并重新审批。
3. 删除分类、知识库或文件前，系统必须提示其包含内容及影响范围，并阻止删除仍包含未处理内容的对象。




# 六. 一期暂不纳入范围


| 需求            | 说明                             |
| ------------- | ------------------------------ |
| 多级部门管理员       | 一期先使用统一知识库管理员角色，后续再按组织架构扩展     |
| 部门知识库与组织架构强绑定 | 涉及部门调整、人员流转、权限继承，一期暂不展开        |
| 公共/专业库内文件夹层级 | 当前优先通过知识库、分类、标签、搜索组织文档，暂不做公共或专业知识库内部的文件夹层级；个人知识库保留轻量分类目录维护 |
| 驳回后处理         | 上传被驳回后流程结束，一期不提供后续上传处理入口       |
| 文件版本差异对比      | 可查看历史版本，但不做版本差异比对              |
| 移动端适配         | 一期聚焦 PC 端使用                    |
