# Ⅱ.知识库模块 · 系统需求说明

# 一. 系统设计原则

1. 业务需求按用户要完成的事情描述，系统需求负责落地页面、交互、数据状态和权限处理 
2. 一期减少孤立菜单，优先按用户流程整合能力 
3. “知识总览”作为知识库主入口，承接知识库浏览、全部资料查看、筛选检索、快速访问等核心能力 
4. “我的上传”保留明确入口，便于用户直接查看上传记录和审批状态 
5. 管理端一期不拆部门管理员、专业管理员等多级角色；保留“知识库管理员”日常治理角色，并增加仅用于全局汇总监管的“超级管理员”视图

# 二. 页面与菜单结构

## 2.1 菜单结构

```text
知识库
├── 知识总览
├── 我的空间
├── 我的上传
└── 知识库管理（知识库管理员、超级管理员可见）
```

| 菜单 | 可见角色 | 页面定位 |
| --- | --- | --- |
| 知识总览 | 全员 | 知识库首页，支持浏览知识库、查看全部可访问文档、筛选检索、快速访问 |
| 我的空间 | 全员 | 展示个人知识库、我的收藏、最近访问、快速访问等个人相关内容 |
| 我的上传 | 全员 | 展示本人上传记录、审批状态、解析状态，并提供上传入口 |
| 知识库管理 | 知识库管理员、超级管理员 | 知识库管理员维护知识库、分类、权限、上传审批、解析异常；超级管理员可查看全库文件汇总 |

> “全库资料 / 所有文档”不再作为必须独立菜单 该能力由“知识总览”的“全部”范围承接 

## 2.2 页面关系

| 起点 | 操作 | 结果 |
| --- | --- | --- |
| 知识总览 | 选择“全部”范围 | 展示当前用户有权访问的全部文档 |
| 知识总览 | 选择某个知识库 | 展示该知识库下的文档 |
| 知识总览 | 选择无权限知识库 | 展示知识库基础信息和申请权限入口，不展示文档 |
| 知识总览 / 我的空间 / 我的上传 | 点击文档 | 默认新开浏览器 tab 进入文件详情页 |
| 文件详情页 | 切换当前库内文件 | 在详情页内切换预览内容 |
| 我的上传 | 发起上传 | 选择目标知识库后提交上传 |
| 知识库管理 | 审批上传或权限申请 | 更新审批结果和相关状态 |

# 三. 知识总览

## 3.1 页面定位

知识总览是知识库模块默认页，承担以下系统能力：

1. 展示知识库分类、公共/专业知识库、个人知识库等入口 
2. 支持查看全部有权文档 
3. 支持查看单个知识库文档 
4. 支持展示无权限知识库，并引导申请权限 
5. 支持快速访问常用知识库和常用文档 

## 3.2 页面结构

```text
┌────────────────────────────────────────────────────────────┐
│ 知识总览                                                    │
├──────────────┬─────────────────────────────────────────────┤
│ 全部          │ 搜索 / 通用筛选 / 排序 / 刷新 / 上传          │
│ 快速访问       │                                             │
│ - 固定知识库    │ 文档列表                                    │
│ - 固定文档      │                                             │
│ 知识库树       │                                             │
│ - 公共知识库    │                                             │
│ - 专业知识库    │                                             │
│ - 个人知识库    │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

## 3.3 系统需求

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-01 | 默认进入知识总览 | 用户进入知识库模块时默认展示知识总览  |
| SR-02 | 全部范围 | 点击“全部”时，右侧展示当前用户有权访问的全部已发布文档  |
| SR-03 | 单库范围 | 点击某知识库时，右侧展示该知识库内当前用户可见的文档  |
| SR-04 | 无权限知识库 | 无权限知识库可见但不可查看文档，右侧展示申请权限入口  |
| SR-05 | 快速访问知识库 | 支持用户固定常用知识库  |
| SR-06 | 快速访问文档 | 支持用户固定常用文档  |
| SR-07 | 最近访问入口 | 支持展示最近访问的知识库和文档，默认展示少量记录，可进入更多记录  |
| SR-08 | 上传入口 | 当用户具备上传能力时，提供上传入口；上传时必须选择目标知识库  |
| SR-09 | 文档打开方式 | 点击文档默认新开浏览器 tab 进入文件详情页  |
| SR-10 | 视图形态 | 文档列表以表格为主，可保留卡片视图，但表格为默认推荐展示；用户的列表/卡片视图选择需要持久化  |
| SR-50 | 文件置顶 | 文件置顶后进入"快速访问"，不在文档列表内强制置顶排序  |
| SR-52 | 取消置顶 | 用户可取消文件或知识库置顶；取消后从快速访问列表移除，不影响文档原有排序和访问记录 |

## 3.4 筛选规则

| 场景 | 筛选项 |
| --- | --- |
| 全部范围 | 文件名/正文关键词、知识库、文件类型、上传时间、更新时间等通用筛选项 |
| 单个知识库 | 通用筛选项 + 当前知识库定义的标签、生效年份、专业属性等筛选项 |
| 无权限知识库 | 不展示文档筛选项 |

> 全部范围下不同知识库的标签体系不一致，库内标签、专业属性等筛选项不做合并展示 

## 3.5 检索与排序补充规则

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-53 | 全文检索边界 | 正文关键词仅检索已完成解析、已发布且当前用户有查看权限的文档；未解析完成的文件仅支持文件名检索 |
| SR-54 | 排序字段 | 全部范围、单库范围、我的收藏均支持按最近更新、上传时间、文件大小、文件名称排序 |

# 四. 文件详情页

## 4.1 页面定位

文件详情页用于在线阅读单个文档，并提供下载、收藏、历史版本、当前库内文档切换等能力 

## 4.2 页面结构

```text
┌────────────────────────────────────────────────────────────┐
│ 返回 / 文件名 / 所属知识库 / 历史版本 / 下载 / 收藏          │
├──────────────┬────────────────────────┬───────────────────┤
│ 当前库文件列表 │ 文档预览区               │ AI辅助内容（预留）    │
└──────────────┴────────────────────────┴───────────────────┘
```

## 4.3 系统需求

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-11 | 新 tab 打开 | 从列表点击文档时，默认新开浏览器 tab  |
| SR-12 | 在线预览 | 中间区域展示文档原文预览  |
| SR-13 | 当前库文件列表 | 左侧展示当前知识库内用户可访问的文档，支持切换预览  |
| SR-14 | 不做复杂跨库切换 | 文件详情页不做跨知识库复杂选择；跨库找文档回到知识总览完成  |
| SR-15 | 下载 | 有文档查看权限的用户可以下载文档  |
| SR-16 | 收藏/取消收藏 | 用户可在详情页收藏或取消收藏文档  |
| SR-17 | 历史版本 | 支持查看文档已有历史版本；主列表不默认展开多版本子表格，对存在历史版本的文件在列表中以 icon 标记，点击可查看历史版本  |
| SR-18 | 解析状态提示 | 解析中、解析失败等状态需要清晰提示；解析未完成前不支持正文内容检索  |
| SR-55 | 解析结果查看 | 对已完成解析的文件，详情页可展示或跳转查看文件摘要、解析图片和关联题目；解析结果不可用时须给出状态说明 |

# 五. 我的空间

## 5.1 页面定位

我的空间聚合用户个人相关内容，包括个人知识库、我的收藏、最近访问、快速访问等 

## 5.2 系统需求

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-19 | 个人知识库 | 展示用户个人知识库及其中的文档；支持个人知识库的新建、重命名、删除和在个人分类目录间移动，删除前校验库内文件  |
| SR-20 | 我的收藏 | 展示用户收藏的文档，支持取消收藏、按文件名/正文检索及按最近更新、文件大小、文件名称排序  |
| SR-21 | 最近访问 | 展示用户最近访问过的知识库和文档，按今天、本周、更早分组，支持查看更多历史  |
| SR-22 | 快速访问 | 展示用户固定的知识库和文档  |
| SR-23 | 进入文件详情 | 我的空间中的文档点击后默认新开 tab 进入详情页  |
| SR-24 | 个人库上传 | 用户可向个人知识库上传文档，上传后进入解析流程，不走管理员审批  |
| SR-56 | 个人分类目录 | 个人知识库支持分类目录的新建、重命名、移动、删除；删除前校验并提示其中的文件和子目录 |
| SR-57 | 个人文件移动 | 用户可在个人分类目录内移动文件；向专业库移动时需选择目标库、校验上传权限，并按非个人库上传流程重新审批 |

# 六. 我的上传

## 6.1 页面定位

我的上传用于集中处理“上传文档”相关事项，包括发起上传、查看审批状态、查看解析状态、查看驳回原因 

## 6.2 系统需求

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-25 | 上传入口 | 支持点击上传并选择目标知识库  |
| SR-26 | 上传记录 | 展示当前用户所有历史上传记录  |
| SR-27 | 状态筛选 | 支持按待审批、已撤回、解析中、已停止、已发布、已驳回、解析失败等状态筛选  |
| SR-28 | 驳回原因 | 上传被驳回时展示驳回原因  |
| SR-29 | 撤回申请 | 待审批的上传记录提供“撤回申请”操作；撤回后更新为已撤回，不再进入审批和解析  |
| SR-30 | 个人库免审批 | 上传至个人知识库时直接进入解析  |
| SR-31 | 非个人库需审批 | 上传至公共、专业等非个人知识库时进入管理员审批  |
| SR-51 | 先审批后解析 | 非个人库文档审批通过后才触发解析，驳回的文档不进入解析流程，避免浪费解析资源  |
| SR-58 | 审核与解析进度 | 我的上传展示全部上传记录的审核阶段和解析阶段进度，并可查看单条记录的当前节点、处理时间和处理结果 |
| SR-59 | 解析控制与结果 | 解析中允许上传人停止解析；解析失败展示异常原因并允许上传人或管理员重新解析；解析完成后提供查看文件、摘要、图片、关联题目的入口 |

# 七. 知识库管理

## 7.1 页面定位

知识库管理面向知识库管理员，用于维护知识库、分类、权限、上传审批和解析异常 

## 7.2 管理功能

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| SR-32 | 知识库列表 | 展示公共、专业知识库集合，列表至少包含分类、文件数、启用状态、知识库名称；支持按知识库名称/简介关键词、分类、启停状态筛选  |
| SR-33 | 新建知识库 | 管理员可以新建知识库，并维护基础信息  |
| SR-34 | 编辑知识库 | 管理员可以修改知识库名称、说明、分类、标签等  |
| SR-35 | 停用/启用知识库 | 停用后普通员工不可见其文档；管理员仍可在管理端查看和重新启用  |
| SR-36 | 分类维护 | 管理员可新建根分类和子分类，并对分类重命名、移动、删除；删除前需迁移或清空其下知识库  |
| SR-37 | 上传审批 | 管理员可以审批员工提交到非个人知识库的文档；审批列表展示文件名、目标知识库、提交人、提交时间、审批状态，通过或驳回后通知申请人，驳回必须填写原因  |
| SR-38 | 权限申请审批 | 管理员可以审批员工提交的知识库权限申请；申请列表展示申请人、目标知识库、申请理由、申请状态，通过或驳回后通知申请人，驳回应填写原因  |
| SR-39 | 解析异常 | 管理员可以查看专业库和个人库汇总的解析失败记录；列表展示文件名、所属知识库、上传人、上传时间，并支持查看日志、重试、删除异常记录  |
| SR-40 | 文档管理 | 管理员可以对库内文档执行隐藏、删除、更新等管理操作  |
| SR-48 | 文件移动 | 支持将文件移动到目标知识库/目录：个人文件可在个人目录间移动，也可在具备目标库上传权限时移入专业库并重新审批；专业/公共库文件仅可在对应专业/公共库范围内由管理员移动  |
| SR-49 | 目录移动 | 支持移动分类目录、个人目录的层级位置  |
| SR-60 | 全库文件汇总 | 超级管理员可查看所有专业库和个人库文件汇总列表，用于监管与审计；汇总列表不绕过文件内容访问、下载和修改权限校验 |

## 7.3 一期角色规则

| 角色 | 管理范围 |
| --- | --- |
| 知识库管理员 | 管理全部知识库、分类、上传审批、权限申请、解析异常 |
| 超级管理员 | 查看所有专业库和个人库的文件汇总及全局状态；不承担部门/专业分级管理职责，文件内容操作仍受权限校验 |
| 普通员工 | 不进入知识库管理，不具备编辑、删除已发布库内文档的能力 |

> 一期不做部门管理员层级；后续若要增加部门管理员，需要与组织架构、部门调动、角色权限联动 

# 八. 权限模型

## 8.1 授权对象

| 授权方式 | 说明 |
| --- | --- |
| 角色授权 | 将知识库授权给某个角色，角色下用户自动获得对应访问能力  |
| 个人授权 | 将知识库直接授权给某个用户，用于处理个别申请或特殊场景  |

用户最终可访问知识库范围 = 角色授权范围 + 个人授权范围 

## 8.2 权限级别

| 权限级别 | 包含能力 |
| --- | --- |
| 仅查看 | 查看、预览、下载文档 |
| 可上传 | 在仅查看基础上，可向知识库提交上传；非个人库上传需审批 |
| 可管理 | 管理库内文档、审批上传、处理库内异常 |

> 普通员工即使上传了文档，也不能删除已发布到公共或专业知识库中的文档；删除、隐藏、更新等操作由管理员处理 

## 8.3 文件状态

| 状态 | 普通员工可见性 | 说明 |
| --- | --- | --- |
| 待审批 | 仅上传人可见 | 等待管理员审批  |
| 已驳回 | 仅上传人可见 | 上传人可查看原因，本次上传流程结束，不提供后续上传处理入口  |
| 已撤回 | 仅上传人和管理员可见 | 上传人撤回待审批申请后产生，不进入审批和解析 |
| 解析中 | 上传人和管理员可见 | 上传人可停止解析，尚不能正文检索 |
| 已停止 | 上传人和管理员可见 | 解析被主动停止，不向其他用户发布 |
| 解析失败 | 上传人和管理员可见 | 展示异常原因，可重新解析  |
| 已发布 | 有知识库查看权限的用户可见 | 可预览、下载、收藏、检索  |

# 九. 检索与性能要求

| 编号 | 要求 | 说明 |
| --- | --- | --- |
| SR-41 | 全部范围检索 | 支持在用户有权文档范围内按关键词检索  |
| SR-42 | 单库检索 | 支持在单个知识库内按关键词和库内属性检索  |
| SR-43 | 分页 | 文档列表必须分页加载  |
| SR-44 | 排序 | 全部范围和单库范围均支持常用排序  |
| SR-45 | 性能预留 | 全部范围文档较多时，可引入索引、缓存或异步查询优化  |

# 十. 一期暂不实现

| 项目 | 说明 |
| --- | --- |
| 独立“全库资料”菜单 | 由知识总览的“全部”范围承接  |
| 文件详情页跨库复杂切换 | 跨库查找回到知识总览完成  |
| 部门管理员、多级管理员 | 后续结合组织架构扩展；一期仅保留知识库管理员和超级管理员全局汇总视图  |
| 公共/专业知识库内文件夹层级 | 一期通过知识库、分类、标签、搜索组织文档；本次新增的"目录移动"指知识库分类和个人分类目录层级移动，不等同于公共/专业库内文件夹层级  |
| 驳回后处理 | 上传被驳回后流程结束，一期不提供后续上传处理入口  |
| 历史版本差异对比 | 一期只查看历史版本，不做差异比对  |
