# 厂站涉网AI助手扩充计划

## 依据材料

- 主文档：[厂站涉网运行智能辅助与能力提升AI助手-20260324.docx]
- 参考范式：[2022年度华东电网典型操作任务编写说明.pdf]

## 已确认的现状

- 主文档当前主线较清晰，现有结构可归纳为：`背景与目标`、`建设内容`，其下重点是 `厂站运行知识体系构建`、`涉网业务智能辅助`、`涉网能力提升`。
- 参考 PDF 的价值不在“照抄章节”，而在于借鉴其编写方法：按 `设备/专业分类`、`典型任务分解`、`操作说明`、`特殊场景`、`术语与边界` 来组织内容，结构更适合一线运行与运检使用。
- 当前主文档偏“方案介绍”，缺少更强的专业化骨架，尤其是火电涉网控制、调度协同、继保安控、运检闭环、考核评价与训练题库等内容。

## 扩充目标

- 把现有文档从“概念性方案说明”扩展为“面向实际业务场景的建设方案 + 知识体系 + 应用场景 + 训练评估框架”。
- 在视角上同时覆盖：
  - 火电发电企业：AGC、AVC、一次调频、PSS、励磁/调速、并网管理、涉网考核、异常处置、典型操作。
  - 地方电力公司运检：继电保护、安全自动装置、调度配合、设备操作、异常处置、培训取证、知识闭环。
- 让文档更像“可直接指导项目立项/汇报/实施”的材料，而不是单纯介绍 AI 能力。

## 正式目录稿

- 整体建议按照 `建设背景 -> 建设边界 -> 知识底座 -> 业务辅助 -> 能力提升 -> 架构实施 -> 安全治理 -> 建设成效` 的逻辑展开，先讲为什么建设、服务谁、解决什么问题，再讲怎么建设、怎么应用、怎么落地。

### 一、项目背景与建设目标

#### 1.1 建设背景

- 新型电力系统背景下，厂站涉网运行复杂度持续提升，调度协同、快速响应和规范执行要求显著提高。
- 火电企业和地方电力公司运检在规程执行、异常处置、经验传承和专业训练方面均面临知识分散、经验依赖强、检索效率低等共性问题。
- 大模型、知识库和 RAG 技术的发展，为构建面向厂站涉网运行的智能辅助能力提供了技术基础。

#### 1.2 现状问题

- 涉网相关资料分散在规程制度、典型操作、事故通报、两票、技术监督资料和历史案例中，缺乏统一知识组织。
- 典型操作、故障处置和专业培训较多依赖个人经验，标准调用和经验复用效率不高。
- 面向火电涉网控制和地方公司运检协同的专业化场景支撑不足，现有材料偏静态、偏分散。

#### 1.3 建设目标

- 构建统一的厂站涉网运行知识底座，实现知识汇聚、结构化治理和动态更新。
- 围绕典型操作、故障处置、火电专项和运检专项场景形成业务辅助能力。
- 围绕岗位能力建设，形成训练评估、经验沉淀和持续优化闭环。

### 二、适用对象与建设边界

#### 2.1 适用对象

- 火电发电企业运行、热控、继保、生产技术及管理人员。
- 地方电力公司调控、运检、继电保护、监控及专业管理人员。

#### 2.2 建设范围

- 覆盖并网运行、典型操作、异常处置、专业问答、培训评估等业务需求。
- 覆盖规程制度、典型任务、案例经验、考核规则和训练题库等知识范围。

#### 2.3 建设边界

- 系统主要提供知识服务和业务辅助，不替代正式调度指令、操作票签发和现场执行管理。
- 对复杂故障、高风险操作、定值变更、保护退出等事项，仅提供参考依据和流程提醒，最终由专业人员确认。
- 涉密信息、敏感生产控制信息和正式执行类指令应纳入专门的权限控制和人工审核机制。

### 三、厂站涉网运行知识体系构建与知识服务

#### 3.1 知识来源体系

- 调度规程、并网运行管理规定、典型操作票、反事故措施、事故通报、两票、厂站规程、试验报告、考核细则等。
- 火电涉网控制资料，如 AGC、AVC、一次调频、PSS、励磁、调速、涉网试验和性能考核资料。
- 地方电力公司运检资料，如继电保护运行规程、安全自动装置管理、标准作业、缺陷案例和协同流程资料。

#### 3.2 知识结构设计

- 按 `专业域、设备对象、运行场景、操作任务、风险点、处置要求、依据条款` 组织知识。
- 重点建立 `专业-设备-场景-任务-风险-依据` 的多维知识骨架。
- 支持典型操作、故障处置、汇报要求、案例教训、考核规则等知识单元的结构化表达。

#### 3.3 知识加工与治理

- 开展文档解析、OCR、结构化切片、标签标注、版本管理和生效废止管理。
- 建立来源溯源、权限分级、知识审核和经验回流机制。
- 形成面向厂站长期使用的知识更新与治理闭环。

#### 3.4 知识体系与 RAG 融合机制

- 通过关键词检索、语义检索、规则过滤和结果重排序，实现知识精准召回。
- 对检索结果进行依据溯源、条款定位和场景化组织，提升问答可信度。
- 将知识底座与典型操作、故障处置、培训评估等场景应用打通，形成统一支撑能力。

#### 3.5 知识检索与问答服务

- 面向规程、典型操作、案例和制度文件提供统一检索与问答服务。
- 支持条款定位、摘要提炼、关联推荐和原文出处展示。
- 重点解决资料分散、检索困难、知识调用效率低的问题，为第四章业务辅助提供知识基础。

### 四、涉网业务辅助场景

- 建设原则：遵循 `知识驱动、场景聚焦、辅助为主、人工确认、逐步深化` 的思路，首期优先形成可落地、可推广的知识服务与业务辅助能力。

#### 4.1 典型操作业务辅助

- 围绕一次设备、保护安控、特殊厂站和特殊运行方式，提供典型操作相关知识辅助。
- 提供前置条件核对、操作步骤提示、风险点提醒、依据引用和异常停止提示。
- 重点服务于操作准备、学习、预演和现场核对，不替代正式操作票和调度许可流程。
- 可实现示例：`500kV线路停役典型操作辅助`
  - 系统识别设备对象、操作目标和适用场景，必要时补充确认保护安控和特殊方式信息。
  - 系统检索典型操作票、运行规程、保护安控说明和历史易错点，形成当前场景下的辅助知识集合。
  - 系统输出前置条件清单、步骤提示、风险点提醒、异常停止与汇报提示以及依据来源。
  - 对关键步骤仅提供参考说明和原文依据，不自动生成操作命令。

#### 4.2 故障与异常处置业务辅助

- 围绕涉网运行中的典型异常和故障场景，提供事件识别、处置原则匹配和分步排查提示。
- 提供异常汇报模板、汇报对象匹配、时限提醒、关键信息归集和案例参考。
- 对复杂故障和高风险场景，仅提供参考建议和依据支撑，最终方案由专业人员确认。
- 可实现示例：`机组一次调频异常退出辅助处置`
  - 系统识别一次调频退出、响应异常等问题，并引导补充机组负荷、控制方式、告警信息和运行工况。
  - 系统检索一次调频管理要求、控制逻辑说明、异常案例和考核条款，形成场景化参考信息。
  - 系统输出优先核查项、可能影响范围、建议汇报要点、考核关注点和依据来源。
  - 对复杂异常仅提供排查顺序和参考建议，不替代现场分析和生产指挥流程。

#### 4.3 火电发电企业专项业务辅助

- 围绕并网运行管理、调度纪律执行和涉网设备运行管理形成火电专项知识辅助。
- 面向 AGC、AVC、一次调频、PSS、励磁、调速等控制系统提供专业问答和场景辅助。
- 面向深度调峰、启停、解列、涉网试验和涉网考核等场景提供分析支撑和复盘参考。
- 首阶段重点实现知识汇聚、场景问答和辅助分析，后续逐步拓展至考核闭环、经验沉淀和专项训练。
- 可实现示例：`深度调峰工况下AGC与一次调频性能辅助分析`
  - 系统识别机组类型、负荷区间和问题场景，定位当前问题所属的控制性能分析场景。
  - 系统检索 AGC、一次调频、调速系统、考核规则及整改资料，汇总相关知识片段。
  - 系统输出性能影响因素提示、核查路径建议、考核指标说明、类似案例和整改经验参考。
  - 输出结果用于支撑运行分析和专业复盘，不替代正式试验、性能测试和技术结论。

#### 4.4 地方电力公司运检专项业务辅助

- 围绕继电保护、安全自动装置、一次二次设备操作和异常分析形成运检专项辅助。
- 面向调控-运检-现场协同提供标准查询、流程提醒、岗位协同和信息报送支撑。
- 面向培训、取证、复证和实战演练提供知识调用和经验传承支撑。
- 重点服务于知识调用、标准执行和流程支撑，不替代现行管理流程和专业审批机制。
- 可实现示例：`500kV线路保护异常信号运检辅助分析`
  - 系统识别设备对象、保护类型、站内间隔和运行方式，并提示补充必要信息。
  - 系统检索继电保护规程、装置说明、典型缺陷案例、标准作业资料和涉网影响说明，形成关联参考内容。
  - 系统输出优先核查项、可能关联回路或装置、需通知的岗位、记录报送要点和依据来源。
  - 对涉及定值变更、装置退出和方式调整等敏感事项，仅提供制度和流程提醒。

### 五、能力提升与训练评估体系

#### 5.1 训练内容设计

- 围绕典型操作、异常处置、调度协同、火电专项和运检专项构建训练内容。
- 以规程制度、案例经验和业务辅助场景为基础构建训练题库和情景材料。

#### 5.2 训练方式设计

- 支持智能出题、定向训练、案例复盘和情景化推演。
- 支持针对不同岗位和专业方向开展差异化训练。

#### 5.3 能力评估机制

- 建立岗位能力画像、薄弱项识别和训练结果跟踪机制。
- 建立典型操作、异常处置和协同报送等维度的评估指标。

#### 5.4 持续优化闭环

- 承接第四章中的业务辅助场景，形成“知识调用-场景辅助-训练评估-经验回流”的闭环。
- 将高频问题、典型错误和优秀经验回流至知识库和训练体系。

### 六、系统架构与实施路径

#### 6.1 系统总体架构

- 构建 `知识底座、RAG 检索、场景应用、训练评估` 四层体系。
- 形成知识接入、知识服务、业务辅助、训练评估的统一技术框架。

#### 6.2 数据与知识处理流程

- 开展文档接入、结构化解析、知识审核、发布应用和知识回流。
- 建立多源知识接入与统一管理机制。

#### 6.3 分阶段实施路径

- 第一阶段：完成重点资料接入、知识底座建设和基础检索问答能力。
- 第二阶段：上线典型操作、故障处置、火电专项和运检专项辅助能力。
- 第三阶段：完善训练评估、经验回流和持续优化机制，逐步扩大试点范围。

### 七、安全合规与治理要求

#### 7.1 权限与安全控制

- 建立权限分级、访问控制、审计留痕和涉密边界管理机制。
- 对敏感知识、关键业务流程和高风险内容实行严格控制。

#### 7.2 人工校核机制

- 对生成式内容建立人工复核和使用边界说明机制。
- 对高风险场景、关键结论和正式执行事项强化人工确认。

#### 7.3 知识治理与合规要求

- 确保知识来源合法、版本一致、使用可追溯。
- 建立知识审核、更新发布和问题纠偏机制。

### 八、预期成效与评价指标

#### 8.1 建设成效

- 提升规程调用效率、典型操作准备效率和异常处置支撑能力。
- 提升火电企业涉网运行分析能力和地方公司运检协同能力。
- 提升专业培训、经验传承和知识沉淀效果。

#### 8.2 评价指标

- 检索效率、答复准确率、训练覆盖率、处置规范率、经验沉淀数量等量化指标。
- 响应提速、差错降低、培训效率提升、专业协同增强等业务指标。
